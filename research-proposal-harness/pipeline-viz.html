aSSIST MBA · Research Automation

Research Proposal Harness

자유형식 아이디어 텍스트를 입력하면, 검증된 선행연구 분석과 함께 aSSIST MBA 양식에 맞는 연구계획서 초안을 자동 생성하는 6단계 멀티 에이전트 파이프라인.

개요 · 특장점
파이프라인
피드백 루프

하네스의 목적

MBA 연구계획서 작성 과정에서 누적되는 4가지 병목을 단일 파이프라인으로 해소한다.

왜 이 하네스가 필요한가

MBA 연구계획서 작성은 변수 정의의 모호함, 선행연구 4개 소스 수동 탐색, 출처 신빙성 검증, 독창성·중복 판단 4단계에서 매번 반나절~하루의 시간을 소모한다. 각 단계의 누적 오류는 지도교수 신뢰도 문제와 계획서 반려로 이어진다. 이 하네스는 가설 정제부터 PDF 생성까지 자동화하면서, 두 번의 인간 검토 게이트와 두 단계 자동 검증 레이어로 품질을 확보한다. 연구자가 직접 개입하는 시간은 단 두 번 — 가설 확인과 초안 검토.

핵심 특장점

단일 LLM 호출이나 일반 검색 도구로는 달성하기 어려운 8가지 차별점.

🛡️

2단계 자동 검증 시스템

Validator A는 출처 신빙성(URL·게재지·메타데이터), Validator B는 클레임-근거 정합성을 교차 검증. 탐지된 할루시네이션은 blocked_claims로 하드 블록되어 최종 계획서 어디에도 사용되지 않는다.

🌐

하이브리드 선행연구 탐색

국내 KCI·RISS는 Exa로 직접 크롤링, 국제 논문은 Google Deep Research로 multi-step autonomous research를 위임한다. 단일 검색 도구로는 닿지 못하는 방대한 학술 소스를 통합 수집한다.

🎓

MBA 연구 특화 분석

aSSIST 6섹션 양식에 자동 매핑, RBV·TAM·TQM 등 MBA 핵심 이론 필수 연결, 양적 연구 시 통계적 검정력 분석을 자동 포함. 일반 학술 글쓰기 도구와 본질적으로 다르다.

⚙️

실행 가능성 자동 점검

데이터 수집 가능성 · 표본 크기 · 방법론 복잡도 · 일정 4축을 자동 평가하여 green/yellow/red로 등급화. 비현실적인 연구 계획을 사전에 차단하고 완화 방안을 제시한다.

🔄

자동 피드백 루프 4종

통과 논문 부족 시 자동 재수집, 가설 중복 위험 시 대안 3개 자동 생성, 근거 신뢰도 저하 시 분석 재실행, 섹션별 부분 재작성. 인간이 매번 지시하지 않아도 스스로 보정한다.

⚡

모델 분업 최적화

구조화·작성은 Sonnet 4.6(속도), 판단·추론·할루시네이션 탐지는 Opus 4.7(정확도). 전 단계를 Opus로 돌리는 것보다 30~40% 저렴하면서도 검증 품질은 유지한다.

✅

할루시네이션 방지 다중 레이어

클레임-초록 교차검증으로 가짜 인용 차단, BibTeX 메타데이터 검증으로 et al./Unknown/하이픈 오류 사전 검출, 프리프린트 출처는 자동 명시. 지도교수가 인용을 검토할 필요 없는 수준의 정확도.

📦

즉시 사용 가능한 산출물

xelatex로 직접 PDF(setup-latex.sh 실행 시), 없으면 Overleaf ZIP 자동 폴백. HTML 미리보기 + references.bib까지 동시 생성. aSSIST 양식 100% 준수, NanumMyeongjo·kotex·indentfirst 설정 완료.

전체 파이프라인

노드를 클릭하면 우측 패널에 상세 정보(모델·입출력 스키마·처리 단계·피드백 루프)가 표시됩니다. 점선 곡선은 자동 피드백 루프를 나타냅니다.

자동 피드백 루프 다이어그램

파이프라인이 스스로 재시도하는 4종 루프. 인간이 개입하지 않고도 품질 기준에 도달할 때까지 자동 보정한다.

VA → A2
통과 논문 부족 시 자동 재수집
Validator A가 3단계 스크리닝 통과 논문이 final_count < 5로 판정하면, A2가 검색 쿼리를 확장(키워드 변형·연구 기간 확장)하여 자동 재수집한다. 국내(Exa) + 국제(Deep Research 핸드오프) 양쪽 모두 재시도.
최대 반복: 2회
A3 → Gate 1
중복 위험 시 대안 가설 자동 제시
A3가 선행연구와 유사도 0.8 이상인 논문 2편 이상 발견 → duplication_risk: high. gap 분석에서 도출한 미연구 영역을 활용해 대안 가설 최대 3개를 자동 생성하여 Gate 1로 복귀, 사용자가 선택하도록 한다.
최대 반복: 사용자 결정에 따름
VB → A3
근거 신뢰도 저하 시 자동 재분석
Validator B가 클레임-초록 교차검증에서 overall_reliability: low로 판정하면, 의심 클레임 목록(reanalysis_targets)을 A3에 전달하여 재분석. A3는 해당 클레임의 논문 초록을 다시 확인하고 수정된 gap·유사도 분석을 출력한다.
최대 반복: 1회
Gate 2 → A4
초안 수정 요청 시 부분/전면 재생성
사용자가 [B] 섹션 수정 → "B 1 배경에 통계 추가해 주세요"처럼 입력하면 해당 섹션만 재생성. [C] 전면 재작성 → 전체 피드백 입력 → A4 전체 재실행. 다른 섹션의 인용·구조는 보존된다.
최대 반복: 무제한

루프 작동 원리

각 루프는 검증 에이전트가 명시적 boolean 또는 enum 신호를 반환해야 발동한다.

// 1. VA → A2 — 통과 논문 부족
if (validator_a.final_count < 5) {
  agent2.rerun({ query_expansion: true, retry_count: n+1 });
}

// 2. A3 → Gate 1 — 중복 위험
if (agent3.duplication_risk === "high") {
  gate1.show({ alternatives: agent3.alternatives });  // 3개 대안
}

// 3. VB → A3 — 근거 신뢰도 저하
if (validator_b.overall_reliability === "low") {
  agent3.reanalyze({ flagged_claims: validator_b.hallucination_flags });
}

// 4. Gate 2 → A4 — 초안 수정
if (gate2.action === "revise_section") {
  agent4.regenerate({ revise_only: gate2.sections });
} else if (gate2.action === "rewrite_all") {
  agent4.regenerate({ feedback: gate2.feedback });
}
