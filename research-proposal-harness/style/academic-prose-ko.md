# 한국어 학술 문체 규칙

terse-academic-prose 원본 12개 규칙의 한국어 학술 글쓰기 적용판.
aSSIST MBA 연구계획서 작성 기준.

## 규칙

**1. 섹션 첫 문장은 행동이다.**
"본 연구는 ~을 목적으로 한다"가 아니라 "본 연구는 ~을 비교한다 / 분석한다 / 검증한다"로 시작한다.
배경 설명 단락을 섹션 맨 앞에 두지 않는다.

**2. 한 문장 한 생각.**
문장 두 개를 "-며, -고" 접속사로 이어붙이지 않는다.
다음 문장은 이전 문장 위에 쌓인다.

**3. 금지 표현 — 삭제하거나 구체적 표현으로 대체한다.**

| 금지 표현 | 대체 |
|-----------|------|
| 매우 중요한, 매우 유의미한 | 수치 또는 구체적 의미로 대체 |
| 다양한, 여러 가지 | 몇 가지(n가지)로 명시하거나 열거 |
| 광범위한, 포괄적인, 심층적인 | 범위를 수치나 대상으로 명시 |
| 본 연구는 최초로, 최초의 연구 | 실제로 필요한 경우에만, 근거 있을 때만 |
| 주목할 만한, 흥미롭게도 | 삭제 — 독자가 판단한다 |
| 패러다임 전환, 혁신적인, 획기적인 | 삭제 또는 구체적 변화 서술 |
| ~에 대한 연구가 필요하다 | 직접 연구 목적으로 서술 |
| ~함으로써 ~에 기여할 것으로 기대된다 | 삭제 또는 기여 내용 직접 서술 |
| ~되어지다 (이중 피동) | ~되다 |
| ~하고 있는 것으로 나타났다 | ~한다 / ~나타났다 |
| 현재 현황, 역할을 담당하다 | 현황, 역할을 한다 |
| ~할 필요성이 있다 | ~해야 한다 |

**4. 형용사 대신 수치.**
"높은 성과"가 아니라 "생산성 X% 향상"으로 쓴다.
측정 지표가 없으면 측정 방법을 명시한다.

**5. 한계는 사실처럼 서술한다.**
"본 연구의 한계로는 ~이 있으나, 향후 연구에서 보완될 것이다"가 아니라
"본 연구는 X 산업 Y기업에 한정되므로 결과의 일반화에 제약이 있다"로 쓴다.

**6. 주어는 "연구자(들)" 또는 시스템·대상.**
"~라고 볼 수 있다", "~라고 생각된다"는 삭제한다.
"본 연구는 ~을 분석한다."처럼 주체를 명확히 한다.

**7. 동기 단락을 과도하게 쓰지 않는다.**
배경 설명은 1–2문장으로 충분하다.
주제의 중요성을 한 단락 이상 설명하기 전에 연구 행동을 먼저 서술한다.

**8. 연구 기여와 결론은 번호 목록.**
"본 연구는 학문적으로 의미 있는 기여를 한다"가 아니라:
1. 스마트 팩토리 도입 수준이 중소기업 생산성에 미치는 영향을 실증 분석한다.
2. KPI 3종(OEE, 생산량, 불량률)을 측정 지표로 정의한다.

**9. 반복 문장을 제거한다.**
한 단락에서 처음 문장과 마지막 문장이 같은 말을 하면 더 구체적인 문장을 남기고 나머지를 삭제한다.

**10. 접속 표현은 기능적으로만.**
"따라서", "그러므로", "그러나", "다음으로"는 허용한다.
"중요한 점은", "주목할 만한 것은", "특히 흥미로운 것은"은 삭제한다.

**11. 수식·표·그림이 서술을 대체한다.**
정확한 수치나 관계가 표나 수식으로 표현 가능하면 산문으로 다시 설명하지 않는다.
"표 1에서 확인할 수 있듯이"로 충분하다.

**12. 결과를 부풀리지 않는다.**
"뛰어난 성과를 달성했다"가 아니라 "OEE X% 향상, 불량률 Y%p 감소를 달성했다"로 쓴다.

## 한국어 특유 추가 규칙

**K1. "본 연구는"을 매 단락 첫머리에 반복하지 않는다.**
두 번 이상 연속 사용 시 주어를 생략하거나 명확한 다른 주어로 대체한다.

**K2. 명사화 남용 금지.**
"~을 실시함으로써", "~의 분석을 통하여"보다 "~을 분석하여"처럼 동사형을 유지한다.

**K3. 경어 혼용 금지.**
학술 논문은 "~한다", "~이다" 체계 통일. "~합니다", "~입니다"를 쓰지 않는다.

**K4. 이중 부정 금지.**
"~하지 않는 것은 아니다"는 "~한다"로 고쳐 쓴다.

**K5. "등"을 열거 없이 쓰지 않는다.**
"스마트 팩토리 등"이 아니라 "스마트 팩토리, IoT 센서, MES 등 3종"처럼 열거 후 사용한다.

## 편집 체크리스트

섹션을 작성한 후 아래 순서로 점검한다:

- [ ] 첫 문장이 행동(동사)으로 시작하는가? (규칙 1)
- [ ] 금지 표현이 포함되어 있지 않은가? (규칙 3, K1–K5)
- [ ] 형용사를 수치로 대체할 수 있는 곳은 없는가? (규칙 4, 12)
- [ ] 한 문장에 두 아이디어가 묶여 있지 않은가? (규칙 2)
- [ ] 앞 문장과 같은 내용을 반복하는 문장은 없는가? (규칙 9)
- [ ] 삭제 가능한 접속 표현이 있는가? (규칙 10)
- [ ] 표·수식으로 표현된 내용을 산문으로 다시 쓰고 있지는 않은가? (규칙 11)
- [ ] "본 연구는"이 연속 두 단락에 반복되지 않는가? (K1)
- [ ] 명사화 구조 대신 동사형으로 바꿀 수 있는가? (K2)
- [ ] 경어 통일 여부 확인 (K3)
