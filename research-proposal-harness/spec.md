# 내 하네스 설계서

## 1. 하네스 이름과 한 줄 목적

**research-proposal-harness** — 자유형식 연구 아이디어를 입력받아 출처가 검증된 선행연구 분석과 함께 aSSIST MBA 양식에 맞는 논문 연구계획서 초안(.pdf/.html)을 자동 생성한다.

---

## 2. 입력 (하네스가 받는 것)

- 연구자의 자유형식 텍스트 (한국어 또는 영어 혼용)
- 예: "스마트 팩토리 도입이 중소기업 생산성에 미치는 영향을 연구하고 싶어요. 독립변수는 스마트 팩토리 도입 수준, 종속변수는 생산성인데 측정 방법을 모르겠어요."

---

## 3. 출력 (하네스가 내놓는 것)

| 파일 | 설명 |
|------|------|
| `proposal_draft.md` | aSSIST 6섹션 연구계획서 본문 |
| `proposal.pdf` | xelatex 컴파일 최종본 |
| `proposal.html` | 웹 뷰어용 HTML |
| `references.bib` | 검증된 인용 문헌 BibTeX |

---

## 4. 필요한 에이전트

**작업 에이전트**

| 에이전트 | 무슨 일을 하는가 | 모델 |
|----------|-----------------|------|
| Agent 1 (A1) | 모호한 아이디어를 독립변수·종속변수·대상·측정지표가 명확한 학술 가설로 구조화한다 | `claude-sonnet-4-6` |
| Agent 2 (A2) | KCI·RISS·Google Scholar·Exa 4개 소스에서 관련 선행연구를 수집하고 3단계 스크리닝·중복 제거를 수행한다 | `claude-sonnet-4-6` |
| Agent 3 (A3) | 검증된 논문들과 가설을 대조하여 연구 흐름·방법론 분포·유사도·연구 공백(gap)을 도출한다 | `claude-opus-4-7` |
| Agent 4 (A4) | 분석 결과를 통합하여 aSSIST 6섹션 연구계획서 초안을 한국어 학술 문체 규칙에 따라 작성한다 | `claude-sonnet-4-6` |

**검증 에이전트**

| 에이전트 | 작업 결과의 무엇을 검사하는가 | 모델 |
|----------|-------------------------------|------|
| Validator A (VA) | A2가 수집한 논문의 URL 생존 여부·게재지 신뢰도(동료심사/preprint/블로그)·메타데이터 일관성·중복을 검사하고, 통과 논문이 5편 미만이면 재수집 신호를 반환한다 | `claude-opus-4-7` |
| Validator B (VB) | A3의 분석 클레임이 실제 논문 초록·본문으로 뒷받침되는지 교차 확인하고 할루시네이션을 탐지한다. 전체 신뢰도가 low이면 A3 재분석 신호를 반환한다 | `claude-opus-4-7` |

---

## 5. HITL 게이트

| 게이트 | 사람이 최종으로 무엇을 검토·승인하는가 |
|--------|----------------------------------------|
| Gate 1 | A1이 정제한 가설(독립변수·종속변수·대상·측정지표)이 연구자의 의도와 일치하는지 확인하고, 중복 위험이 높을 경우 대안 가설 3개 중 하나를 선택하거나 위험을 감수한다 |
| Gate 2 | A4가 생성한 6섹션 초안을 검토하여 전체 승인·섹션 단위 수정 요청·전면 재작성 중 하나를 선택한다 |
